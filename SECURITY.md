# Security

This repository contains an installation example and no wallet, key material,
network client, or signing implementation. Vulnerabilities in the example or
in a Reuna Labs OCaml Web3 package should be reported privately to
`security@reuna.io`; do not open a public issue for a signing-path defect.

All referenced packages are public, unaudited alphas. Successful installation
or CI does not make them suitable for custody or production-value use.
